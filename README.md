# Gospel Light Church - Building Fund Website

A modern, responsive website for Gospel Light Church's building fund campaign. Built with React, Vite, and Chakra UI.

## Features

- 🏠 Home page with mission statement and progress tracking
- 💰 Donation page with multiple giving options
- 📅 Events page for fundraising activities
- 📸 Gallery showcasing current church, progress, and renderings
- 📝 Updates page with building progress timeline
- 👥 About page with church history and leadership team

## Tech Stack

- React 18
- Vite
- Chakra UI
- React Router
- React Icons

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/yourusername/gospel-light.git
cd gospel-light
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.
